# snap_crackle_and_pop

A visual physics demonstration built in **Python**, exploring higher derivatives of motion through animated objects and mathematical visualization.

### Features

- Visualizes different orders of motion, from acceleration to jerk, snap, crackle, and pop
- Animates objects to demonstrate how successive derivatives describe changes in motion
- Explores the relationship between position, velocity, acceleration, and higher-order derivatives
- Aims to combine real-time visualization with equations and numerical results for verification

### Physics Concepts

- Position: `x(t)`
- Velocity: `v = dx/dt`
- Acceleration: `a = d²x/dt²`
- Jerk: `j = d³x/dt³`
- Snap (jounce): `s = d⁴x/dt⁴`
- Crackle: `c = d⁵x/dt⁵`
- Pop: `p = d⁶x/dt⁶`

### Notes

- Explores higher-order derivatives of position to understand increasingly complex changes in motion
- Uses mathematical models to connect displayed motion with its underlying equations
